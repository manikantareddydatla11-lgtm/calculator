Basic Calculator

Project Overview

The Basic Calculator is a simple and user-friendly web application developed using HTML5, CSS3, and JavaScript. It performs basic arithmetic operations with a clean interface and responsive design.

Objectives

- To practice JavaScript event handling.
- To understand arithmetic operations.
- To learn DOM manipulation.
- To design a calculator using CSS Grid.
- To handle errors such as division by zero.

Technologies Used

- HTML5 – Creates the calculator structure.
- CSS3 – Styles the interface and arranges buttons using CSS Grid.
- JavaScript – Implements calculator functionality and manages application state.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal number support
- Clear (C) button
- Delete (DEL) button
- Equals (=) button
- Division-by-zero error handling
- Responsive user interface
- Safe arithmetic calculations without using "eval()"

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files ("index.html", "style.css", and "script.js") are present.
4. Open "index.html" in your web browser, or use the Live Server extension.
5. Click the calculator buttons to perform calculations.

How It Works

1. The user enters numbers using the calculator buttons.
2. The user selects an arithmetic operator.
3. The user enters the next number.
4. The equals button calculates and displays the result.
5. The clear button resets the calculator.
6. The delete button removes the last entered digit.
7. Division by zero displays an error message.
